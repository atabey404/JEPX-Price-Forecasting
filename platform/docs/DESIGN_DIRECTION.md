# JEPX 平台设计依据：Linear × Mercury

记录日期：2026-11-10。用途：后续日本 JEPX 电价预测平台的持久设计约束。设计实施前应先阅读本文件。

## 用户已明确的要求

1. 学习 linear.app、mercury.com 的UI、设计风格和交互，将适合的原则用于我们自己的平台。
2. 平台提供日语、英语设置；两种语言是完整界面切换，不能在正文中重复堆放双语。
3. UI应精致、有原创性，与四川项目明显区分。沿用业务便利性，重新设计布局与视觉。
4. 先稳定模型，再实施平台。本次仅研究与记录，不代表开始平台开发。

## 研究范围和证据

本次查阅两个官网、Linear官方2024重设计与2026更新文章、Mercury官方公开demo介绍及2026年3月产品更新，并查看四张官方发布的界面/图表图片。

本次没有进入登录后的真实账户，没有完成实时demo的交互遍历。自动浏览器启动受环境限制，视觉观察来自官方已发布图片；动效时长、真实键盘路径、完整响应式表现没有实测。不能把后文拟议参数说成两家官方设计token。

| 来源 | 可确认或观察到的原则 | 在JEPX的转化 |
|---|---|---|
| Linear 2026视觉更新说明及侧栏对比图 | 导航降低视觉权重，当前任务内容优先；图标更精炼，未选项更安静，保留适度垂直间隔 | 左栏做定位，主区域突出价格曲线与核验；当前地区和日期明确 |
| Linear 2024重设计说明及界面图 | 侧栏、标签、页头与面板强调一致的对齐、层级与信息密度 | 将地区/日期/模型筛选放在统一视图工具栏，详情在侧面展开 |
| Mercury官方demo介绍及界面图 | 浅色工作区、分组导航、清晰余额层级、主要动作与次要动作区分 | 少量有意义的价格/误差摘要；一个明确主动作，其他操作收敛到次级入口 |
| Mercury Insights官方更新及配图 | 用时间筛选、交互图表与表格帮助理解金融数据 | 图表和时段明细共享筛选条件，核验结果可定位到具体时段 |

官网营销页与日常工作台承担不同任务：营销页的氛围、插图和展示排版只作品牌参考，工作台优先借鉴产品UI的清晰度与操作效率。

## 整体方向

建议方向：安静、精确、有温度的电力市场研究工作台。吸收Linear的结构与效率，以及Mercury的数据呈现和留白。让用户首先看懂地区、交付日、预测状态和价格形态，再查看模型误差与证据。

以下均为我们的初始设计提案，后续根据原型校准，不是用户已经选定的色号或主题。

- 默认尝试偏暖的浅色画布，白色主要内容面，石墨色正文，低对比中性分隔。
- 可选深色作为后续扩展；不能因为参考Linear就自行认定用户要全黑主题。
- 一种冷静的品牌强调色（可试靛蓝或青蓝），只用于选中、主要动作和关键预测系列。
- 实际价格、候选、基线拥有固定的颜色和线型，不随页面改变。涨跌方向与预测好坏采用不同语义；高电价并不天然等于“好”。
- 紧凑导航与舒展图表并存。表格需要密度，阅读区需要呼吸，不能全部变成大卡片。
- 统一小幅圆角、细边框和轻阴影；层级主要靠排版、间距与背景，不靠厚阴影。

## 字体与基础参数草案

- 英文优先系统无衬线或有合适授权的Inter类字体；日文使用Noto Sans JP或系统日文字体，统一基线和字重。
- 数字启用等宽数字，价格右对齐；数字、单位和期间明确分层。避免在密集数据区使用装饰衬线字体。
- 初始字号：正文14–16px，辅助12–13px，页标题24–30px，核心数字28–36px；日文内容留足行高，不机械套用英文窄行距。
- 间距按4/8px节奏组织；侧栏约216–240px，桌面内容边距24–32px，组件圆角6–10px，仅为起稿范围。
- 普通正文对比度目标至少4.5:1。不能照搬参考图里过浅的文字造成难读；状态同时有文字/图标，不只靠颜色。

## 页面结构草案

导航建议：Overview / Forecasts / Evaluation / Data & Exports。日文分别为概要、価格予測、予測検証、データ・出力。Settings收纳语言等设置。

- 顶部定位层：当前页面和地区。
- 视图工具栏：交付日、地区、模型/基线选择；右侧为当前页面主要动作及导出。
- 首屏：交付日与数据状态，小型摘要，主要价格曲线。首屏不能先被大段介绍或装饰图占满。
- 次级内容：预测差异与时段明细。点选曲线时段或表格行，在右侧详情抽屉显示同期值、误差与时间记录，保留当前筛选。
- 历史核验：按地区、日期范围查看MAE、偏差、相对基线改善，保留样本天数和评估类型。前瞻与事后复算分别标注。

可用性细节：筛选记住上次状态；区域/日期可被链接分享；悬浮提示完整显示时间、系列、价格与单位；图表与表格联动；导出继承当前筛选并说明导出范围。

## 电价图表的特定要求

- 默认48个半小时时段；时间轴明确JST，价格明确JPY/kWh。数据未公布是空缺/待公布，不补0。
- 预测、官方日前价格和两个简单基线可以分别开关；默认保持少量主要曲线，避免彩虹线团。
- 线条细致、端点克制。电价尖峰和低谷必须忠实呈现，不能为了“顺滑高级”使用导致过冲、改变极值或掩盖数据的插值。
- 同时跨地区比较时说明轴范围；不能用不同轴范围制造相同波动错觉。
- 不展示未经建模和验证的置信带，不为了视觉完整虚构未来真实值。
- MAE改善必须指明基线、地区和样本期间；单日前瞻结果不能显示成稳定收益或可靠交易建议。
- 待核验、已核验、输入过期/缺失等状态以短标签直接呈现。技术细节放可展开的来源记录，避免妨碍日常阅读。

## 交互与双语

以下是本项目拟议交互，不代表本次已实测两家行为。

- 简短过渡可先试120–180ms，提供减少动画设置兼容；避免滚动劫持、持续发光和无意义入场动画。
- 日期/地区切换后保留上下文，更新有局部反馈，失败给出可执行的恢复方式。
- 导出及过滤等按钮有文字标签；键盘可达且焦点可见；关键操作不能只在hover时出现。
- 语言切换显示「日本語 / English」，记住选择，切换后保留当前页面、交付日与地区。
- 日期和数字格式尊重语言偏好，但市场时区始终明确为JST，不能因浏览器语言悄悄改变交付日。
- 英文长标签和日文不同字宽均需测试；不能把字号缩到难读以避免溢出。

## 后续设计验收

1. 首屏能立即识别地区、交付日、预测/核验状态和主要曲线。
2. 导航退后，操作位置一致；详情可渐进展开。
3. 配色克制但信息对比足够，数值对齐且单位明确。
4. 预测不佳如实展示；研究状态与真实可用数据一致。
5. 日英切换、空数据、长文本、键盘、桌面与窄屏都验证。
6. 与四川项目在布局、排版、色彩和组件语言上明确区分，同时保留导出与历史对照的便利性。
7. 用真实任务验证：定位一日预测 → 查看某时段偏差 → 对比基线 → 导出所选数据。
8. 原型阶段再确认色板和细节；不复制两家logo、插画、专有字体或完整页面。

## 2026-11-10 界面审阅后的明确调整

删除侧栏Atabey个人信息块、侧栏Research edition / Models under validation卡片、页脚JPY/kWh · JST · Research edition行。删除紫色K字图标，保留简洁Kairo文字标识；加载状态与浏览器图标也不使用该K图标。日英版本一致执行。

## 2026-11-10 商业化字体与介绍首页

按用户要求移除时尚/编辑感衬线字体，工作台与首页统一使用现代商业无衬线。网站根路径为日英双语介绍页，包含真实预测曲线交互、数据到核验流程动效和滚动揭示；底部按钮进入/workspace预测工作台。旧根路径带view参数的分享链接仍转入工作台。动效尊重减少动画设置，避免虚构市场价格或模型精度宣传。

## 2026-11-10 深色主题、可读性与演示升级

用户要求首页和工作台改成深色主题、整体增大字体，并参考Apple的产品展示节奏提升开场演示。首页主标题约42–66px，正文17–18px，工作台普通内容约14–16px、数字31–38px；手机与桌面分别校准。黑色与深蓝灰分层、冰蓝强调色、明暗对比更清晰。桌面首页新增滚动驱动的定帧聚焦：文案逐渐退场，真实预测画面扩大至主舞台；进场使用渐显、浅景深及曲线绘制，流程节点保留交互。小屏与减少动画偏好采用常规布局，退出隐藏文案的键盘焦点。介绍页文案及Kairo介绍页字标不使用英文或日文句号，价格数值的小数精度不变。继续保留无K图标、无个人信息块及底部工作台入口。
