# Hosting

The original platform is hosted at https://jepx-observatory.brilliant-ran.chatgpt.site and currently requires its owner to sign in. Source and retained market data are public here. A fresh deployment needs its own hosting identity and manifest; the original project binding is intentionally omitted.

Run `npm ci` and `npm run dev` from this directory. The build uses Vinext and the included Vite configuration. See package.json for build commands. No credentials or runtime state are bundled.
