## プロジェクト概要

日本卸電力取引所（JEPX）の前日市場価格を予測するため、段階的に進めている研究プロジェクトです。最終的には、翌受渡日の**48コマ（30分単位）のシステムプライスとエリアプライス**を予測することを目指します。初期の地域分析は **東京・関西・九州**を中心に行い、価格データは全9エリアを保存しています。

**現在はデータ整備段階です。価格予測モデルの学習・検証はまだ行っていません。** 架空の予測精度を提示したり、事後実績を入札前に利用できた情報として扱ったりすることはありません。

## ローカルでの利用

Python 3.11以降を使用します。

```sh
git clone https://github.com/atabey404/JEPX-Price-Forecasting.git
cd JEPX-Price-Forecasting
python -m pip install -r requirements.txt
```

リリースの3つのZIPをダウンロードし、**各ZIPの最上位ディレクトリ名を保ったまま、リポジトリのルートに展開**してください。一部のスクリプトは、ZIP内の元データや取得元ページの保存版を必要とします。その後、以下で再処理・確認できます。

```sh
python JEPX_Project/scripts/process_validate.py
python JEPX_Step2/scripts/normalize_supply.py
python JEPX_Step2/scripts/validate_supply.py
python JEPX_Step3/scripts/normalize_weather.py
python JEPX_Step3/scripts/validate_step3.py
```

取得用・欠損予報の処理用スクリプトも付属しています。外部サイトからの再取得は、アクセス制限、公開範囲、過去値の修正に影響されます。保存済みデータの再処理と最新版の再取得は別の操作です。

## 情報の利用時刻と制約

- 入札締切は、受渡日前日の **日本時間10時**です。前日夕方に公表される予測値は、その入札には間に合いません。
- GFSは原則として受渡日の2日前12時UTCを初期時刻とする予報を使用し、**計算・公開に12時間かかるという研究上の仮定**を置いています。過去のサーバー上での初回公開時刻は未検証であり、将来情報の混入が完全に排除されたデータとは断定できません。
- ERA5は事後の再解析であり、当時公表された予報ではありません。対象日の需給・発電実績は研究・評価、または利用可能時刻を考慮した過去値の特徴量に限定します。
- 古い需給実績は1時間値、近年は30分値です。元の粒度を分けて保存しています。九州の2024年3月は両方が存在するため、重複集計しないでください。
- 代表9地点は暫定的な格子点特徴量です。需要や再エネ設備容量による重み付けはしておらず、厳密なエリア平均気象ではありません。

## 今後の計画

項目ごとの利用可能時刻を定義し、最初の統合データセットを作成します。カレンダー・過去価格を用いた基準モデルを作り、公開遅延の仮定を明示して気象特徴量を追加し、日次のローリング検証を進めます。入札前に利用できるエリア需要・再エネ予測の確保、または別モデルによる推定も今後の課題です。
