# 日本 JEPX 日前電力価格予測

[简体中文](README.md) · [English](README.en.md) · [日本語](README.ja.md)

東京・関西・九州を対象に、翌日の電力価格を1日48コマで研究するプロジェクトです。主データ整備、4回のモデル実験、日本語・英語対応の Kairo プラットフォームを実装しました。

[Kairo を開く](https://jepx-observatory.brilliant-ran.chatgpt.site)（現在は所有者のログインが必要） · [初期データ全体](https://github.com/atabey404/JEPX-Price-Forecasting/releases/tag/v0.2.0-data-20261105) · [全アーカイブとハッシュ](docs/ARTIFACTS.json)

## 現在の状況 — 2026年11月10日

基本候補は過去価格とカレンダー情報の12変数を使用する、84日間ローリング学習の HGB 残差モデルです。気象特徴は別途実験しましたが、現在の基本モデルは気象・需給・価格を統合した本番システムではありません。保存済み価格は11月11日受渡分、予測は11月12日受渡分まで含まれます。

共通の106日間（7月29日〜11月11日）の過去比較では、東京／関西／九州の基本候補 MAE は3.686／4.162／3.454 JPY/kWh、前日同時刻基準は4.157／4.797／3.762でした。固定50%修正と28日適応修正は全体を改善しなかったため、基本候補を維持しています。

**基本候補の前向き評価済み受渡日は11月11日の1日だけです。** MAE は5.311／3.700／5.526、前日基準は4.843／3.718／4.042でした。新しい2規則の前向き評価済み日は0です。過去比較は探索的研究であり、将来の安定性を保証しません。11月12日は結果待ちです。

## ローカル実行

```sh
cd platform
npm ci
npm run dev
```

Node 22.13+ が必要です。新しい環境への公開方法は [HOSTING](platform/HOSTING.md) を参照してください。元サイトの識別情報、認証情報、実行状態、依存ディレクトリは含めません。Python 実験は各アーカイブの依存関係と説明に従って実行します。

## プラットフォームと次の段階

ダークテーマの紹介ページには、滑らかなスクロール演出、日英切り替え、末尾のワークスペース入口があります。ワークスペースは地域・日付・モデルの選択、48コマ曲線、過去と前向き結果の区別、出典確認、CSV出力、ブラウザー内の実績取込に対応し、保存済み予測を維持します。

現在は135受渡日・405エリア日の研究スナップショットです。リアルタイム取得、自動推論、クラウドへの取込永続化は未接続です。過去データの初回公開時刻は完全に復元されておらず、事後実績や再解析気象を入札前情報と見なしません。今後は入札締切前の予測を変更せず保存し、全規則を単純基準と比較し、少なくとも28日間の前向き証拠を集めてから昇格を判断します。
