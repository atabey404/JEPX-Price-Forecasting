# JEPX 第三阶段：首轮价格模型与天气增量试验

当前状态：已完成第一轮日滚动研究验证，保留价格＋日历的小型梯度提升树为后续研究候选。**尚未达到实盘稳定或平台搭建条件。天气带来的稳定增益未得到证实。**

## 本轮做了什么

- 采用第四步主表，初始数据范围为2026-04-04至2026-11-06，不新增或修改历史来源。
- 评估2026-07-01至2026-11-06，共129天，每个区域6,192个半小时时段。
- 东京、关西、九州分别建模，预测次日48个时段的区域日前价格；本轮没有训练全国System Price模型。
- 每天用此前84个交付日、4,032条记录重新训练；目标日48条不参与训练。
- 目标为“目标价格－前一天同一时段价格”，预测后再加回前一天价格。
- 两种算法：岭回归、小型直方图梯度提升树。每种分别使用“价格＋日历”和“价格＋日历＋天气”，共12条区域模型线。
- 完成1,548次模型拟合；加上两个简单基线，共输出111,456条预测记录。

## 公平比较与时点

模型、参数、84天窗口在本轮计算前固定，未进行参数搜索。所有候选使用相同的区域、训练日期和评价时段。缩放器仅拟合训练数据；梯度提升关闭随机验证和提前停止。

训练标签来自此前交付日已经出清的日前市场价格，遵循第四步保留的价格发布时间假设。没有使用目标日价格、实际负荷/发电、ERA5或当日成交量作为输入。

气象仍采用12小时计算/发布延迟假设，首次服务器可用时间未验证；不能称为完全验证的无泄漏实盘数据。数据中的已选定较早GFS批次不因模型误差重新选择。

7月至11月的基线结果已在第四步查看过。因此本轮属于**复用历史区间的回顾性比较**，不宣称这是从未查看过的全新测试集，也不等同于事前签发的真实预测。

## 结果概要

MAE单位：JPY/kWh，越低越好。

| 区域 | 前一天基线 | 梯度提升：价格＋日历 | 相对降低 |
|---|---:|---:|---:|
| 东京 | 3.8157 | 3.4411 | 9.82% |
| 关西 | 4.2389 | 3.7380 | 11.82% |
| 九州 | 3.3648 | 3.1051 | 7.72% |

这个核心模型在7、8、9、10月四个完整月均优于前一天基线。但它是在当前回顾性比较后保留的候选，仍需冻结方案后的新数据确认，尚不部署。

![同样时段的模型对比](figures/model_comparison_mae.png)

天气增量较小：梯度提升加入天气后，东京MAE降低约0.24%、关西约0.55%、九州反而上升约1.48%。两类算法、三个区域的配对日误差差值95%区间均跨过0，未达到本轮预先设定的天气增量门槛。**这不等于天气与电价无关，只表示当前点位、变量、模型和样本下没有足够证据证明稳定增益。**

![天气增量区间](figures/weather_increment_ci.png)

95%区间采用7天循环区块重采样、3,000次，比较相同日期的日MAE差值；保留日内相关性和一周范围的时间相关性。它是历史平均误差差值的区间，不是未来价格预测区间，不是普遍有效的概率保证。

## 尚未解决的问题

- 还未取得模型冻结后连续30个交付日的真实前瞻记录；这是本项目拟定的接受门槛，不是通用行业保证。
- 天气和价格历史首次可用时间、修订版本尚未完整验证。
- 四个模型合计出现87条负价输出，均保留在原结果中，没有事后裁剪美化。核心梯度提升候选有28条。正式运行前需要核对目标市场价格约束并单独验证边界处理。
- 没有补入权威节假日、竞价前区域负荷/风光预测、联络线、停机或燃料变量。
- 没有给出收益承诺、交易建议、未来价格区间或当前日期的实盘预测。

## 运行

将第四步成果包解压，保留`JEPX_Step4`文件夹。Python 3.11+：

```sh
python -m pip install -r JEPX_Model_Experiment_01/requirements.txt
python JEPX_Model_Experiment_01/scripts/run_experiment.py --stage4-root /path/to/JEPX_Step4
python JEPX_Model_Experiment_01/scripts/verify_experiment.py --stage4-root /path/to/JEPX_Step4
python JEPX_Model_Experiment_01/scripts/summarize_candidate.py
```

模型字典的预测值为`estimator.predict(X[feature_columns]) + X.price_lag_1d`。不得把残差输出直接当成最终价格。未做负值裁剪或其他事后修正。

## 平台安排

先验证模型，再搭平台。已记录的要求是：**日语/英语完整切换、独立于四川项目的新设计、更精致的界面与交互**。拟以48时段预测时间轴为核心，加入区域同步对照、价格热力图、历史复盘、输入新鲜度和模型版本状态。只有另行验证过的价格区间才会显示为预测带，不会把回测误差区间当作未来价格区间。

下一步优先冻结核心候选、检查异常和边界、完善时点可用性与前瞻留档，再按固定方案验证更有针对性的天气变化/供需特征，避免在同一历史区间反复调到看起来最优。
