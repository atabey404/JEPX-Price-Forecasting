# JEPX — Model Experiment 02

本轮：冻结候选模型参数，增加输出下界保护，补验新日期，并开始竞价结果公布前的研究预测留档。模型仍处于研究阶段，尚未达到平台上线条件。

## 1. 模型和数据

沿用实验01的核心特征 HGB 残差模型：84天滚动训练、预测下一交付日48个半小时时段，东京、关西、九州分别训练。12项输入仅含历史日前价格及日历特征。树参数及输入定义在抓取本轮新数据前冻结，见 docs/frozen_candidate.json；没有新一轮调参。

本轮官方 CSV 在 2026-11-09 08:05:50 UTC（日本17:05:50）取得，含2026-04-01至2026-11-10的日前价格。原始文件、SHA256和接收时间均保留。与上一轮31,248条地区目标价格重叠核对，未发现修订。固定参考日的12项核心特征也与旧底座一致。

天气在上轮未显示稳定增益，因此本轮核心候选不使用天气，不依赖气象历史发布延迟假设。历史回测依然无法证明当时每个输入版本的首次可用时间；当前前瞻留档则有实际输入接收时间证据。

## 2. 输出下界保护

输出采用 max(原始预测, 0.01) JPY/kWh。这是数据口径上的研究保护措施，并非模型学到的新规律；原始预测及修正后结果都保留。官方价格格式依据及适用限制见 docs/SOURCES.md，没有施加上界裁剪。

旧实验四组模型共87个负数预测、99个低于0.01的预测；保护后这些输出不再低于下界。由于保留的真实价格均不低于下界，此项修正不会增加这些样本的绝对误差。此性质不能作为模型能力提升的证据。

## 5. 复核与复现

环境：Python 3.12；pandas 2.2.3；scikit-learn 1.8.0；numpy、matplotlib、joblib、threadpoolctl。模型反序列化仅用于本项目自有文件，并应保持同一 sklearn 版本。

```sh
python scripts/verify_exp02.py
python scripts/score_forward.py --price-csv data/raw/spot_summary_2026_20261109T080540Z.csv
```

第二条用当前快照会返回 PENDING。官方新文件包含11月11日价格后，传入新CSV，即可对已留档预测与两个已留档基线评分；程序核对预测哈希，不会重新训练或改写预测。抓取脚本 scripts/fetch_prices.py 用于取得后续官方快照，应在单独运行目录保存，保留现有接收记录。

scripts/advance_candidate.py 是本轮计算实现，需要前两个交付包解压目录作为 --experiment1-root 和 --stage4-root。现有交付包用于审计，重新计算应在其副本运行。--issue-forward 会拒绝在已有前瞻登记表的目录再次签发；不得为同一交付日反复生成预测后择优。独立复核已验证12组MAE、1728条补验行、144条前瞻行、三区保存模型重放和时间顺序，详见 docs/independent_verification.json。
