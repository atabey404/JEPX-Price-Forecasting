# JEPX Model Experiment 03 — first prospective check

本轮完成11月11日交付日前价格的首次前瞻核验，并在下一次竞价截止前留档11月12日预测。候选模型参数保持不变。当前仅1个交付日完成前瞻评分，尚不能确认模型稳定，平台开发继续等待。

## 本次结果

11月11日的日前价格在11月10日竞价结束后公布，因此可以在物理交付之前核验。这里的“真实值”是官方公布的日前成交价格，不是实时价格，也不是发电量。

| 地区 | 前一日基线 MAE | 7日同刻中位数 MAE | 已留档候选 MAE | 相对前一日基线 |
|---|---:|---:|---:|---|
| 东京 | 4.843 | 6.483 | 5.311 | 恶化9.68% |
| 关西 | 3.718 | 7.594 | 3.700 | 改善0.48%，基本持平 |
| 九州 | 4.042 | 6.869 | 5.526 | 恶化36.70% |

单位JPY/kWh；每地区48个半小时时段。该候选虽然优于7日中位数，但东京、九州未超过更强的前一日基线。不能只选择较弱基线宣称成功。此前11月7—9日属于事后复算，本次属于事前留档预测，两类结果分开评价。

此次表现没有支持模型已稳定优于简单基线的结论，也不能仅凭1天就断言模型长期无效。保留原参数继续积累记录，避免根据当天成绩事后调整并替换预测。

## 误差在哪里

所有分段均按日本时间，6小时一段，每段12个样本，仅作事后诊断。

- 九州06—12时和12—18时，候选MAE分别6.363、6.883，比前一日基线分别增加2.633、2.694。日间接近最低价时段，候选上调偏多；下午高价段也存在低估。
- 东京18—24时的候选MAE为4.928，比基线增加2.344；00—06时也较差。最大单时段误差发生于第25时段（12:00—12:30）：官方12.82，候选30.617，候选未能跟上当日价格低谷。
- 关西06—12时有所改善，但其他时段有抵消，整日只略胜基线。

这些是误差位置，不是已经证实的天气、供需因果，也不是可以明日直接套用的模型选择规则。详细48时段、分段和最大误差记录见data/processed。

## 复核方式

Python 3.12、pandas 2.2.3、scikit-learn 1.8.0；其他依赖见requirements.txt。保存模型只应用于本项目自有文件。

```sh
python scripts/analyze_verify.py
python scripts/score_forward.py --price-csv data/raw/spot_summary_2026_20261110T021940Z.csv
```

第一条重建本轮诊断和验证。第二条给11月11日评分、对11月12日返回PENDING，不重训、不改原预测；收到含11月12日结果的官方CSV后，再传入该新文件即可评分。评分新增独立结果文件，不更新原签发记录。

本目录是固定审计快照。新的签发应在新的运行目录中完成，继承登记表、旧预测、参数及原始接收证据，保存新输入和新接收记录。continue_forward.py会拒绝对已登记目标日重复签发。不要对本目录运行旧advance_candidate.py的main；该文件仅保留原模型/特征函数供其他脚本导入，旧完整复算依赖在上轮交付包中说明。
