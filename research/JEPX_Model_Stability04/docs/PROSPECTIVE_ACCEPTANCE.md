# 后续候选验证规则（2026-11-10事先记录）

1. 三个版本：原HGB、固定50%修正、过去28天自适应修正。每次截止前同时留档，后续同时报告；两个基线为前一日同刻价格和近7日同刻中位数。11月12日的新版本未获得任何成绩。
2. 新版本从11月12日开始，至少积累28个连续交付日，三区每天完整48时段；缺失或错过截止如实记录，不能当作已通过或事后补成前瞻。
3. 每地区分别检查：全期MAE较前一日基线改善至少5%，同时不差于7日中位数；新版本还须不差于原HGB。
4. 28日分为四个连续7日段，每地区至少3段优于前一日基线，最差一段MAE不得比该基线恶化超过10%；同时报告日误差90分位数和最差日。

6. 单日优劣、已有事后回测、模型名称复杂度、漂亮曲线均不能替代上述证据。通过也只代表已完成本阶段研究验收，不自动授权交易或上线。
