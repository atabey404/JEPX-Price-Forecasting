# 日本 JEPX 日前电价预测

[简体中文](README.md) · [English](README.en.md) · [日本語](README.ja.md)

研究东京、关西、九州次日的电价，每个地区每天输出48个半小时时段。目前已完成主数据底座、四轮模型实验，以及日英双语 Kairo 平台的介绍页、预测曲线、时段明细、历史核验和导出功能。

## 当前进展：2026年11月10日

当前主候选使用历史电价和日历特征，以84天滚动 HGB 学习残差，共12项输入。天气增量已单独试验，目前主模型并不是天气、供需、电价全量融合的生产系统。保留数据中，已公布电价覆盖至11月11日交付日，预测覆盖至11月12日；这里的日期指交付日。

106天共同历史比较（7月29日至11月11日）中，东京／关西／九州主候选 MAE 为3.686／4.162／3.454 JPY/kWh，前一日同刻基线为4.157／4.797／3.762。固定50%残差修正、自适应28天修正没有改善总体结果，因此保持原候选。

**原候选真正完成前瞻评分的交付日仅有11月11日这一天**，MAE 为5.311／3.700／5.526，前一日基线为4.843／3.718／4.042。两种新规则的前瞻评分日为0。历史结果属于探索性比较，不能据此宣称模型已稳定；11月12日结果仍待公布。

## 本地运行平台

```sh
cd platform
npm ci
npm run build:pages
npx vite preview --config vite.pages.config.mjs
```

需要 Node 22.13+。独立部署见 [HOSTING](platform/HOSTING.md)。公开代码不含原站点绑定、凭据、运行状态和依赖目录。Python 实验请按对应包的依赖与说明运行，并先解压其上游输入。

## 平台范围与下一步

介绍页使用深色主题、连续缓动的滚动聚焦动画，支持日英切换，底部进入工作台。工作台支持地区、日期、模型筛选、48时段曲线、历史与前瞻分开核验、来源检查、CSV 导出和浏览器本地实际价格导入，保留原签发预测。

本版载入135个交付日、405个地区日的研究快照，尚未接入实时抓取、自动推理或云端持久导入。历史数据首次发布时间尚未完全重建，不能把事后实际或再分析天气默认当作竞价前已知输入。下一步继续事前签发、保留所有版本并逐日评分，至少积累28天前瞻证据后再评估是否升级主模型。
