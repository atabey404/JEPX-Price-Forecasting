# Research and data snapshots

These five complete archives retain scripts, raw/processed data, forecast records, training audits, metrics and figures from the subsequent research milestones. Extract all archives into a common working directory, preserving their top-level directory names. Read each included README for dependencies and source paths. Readable scripts and notes are also mirrored under `research/`.

The three earlier full price, supply/generation and weather archives remain in the public [data release](https://github.com/atabey404/JEPX-Price-Forecasting/releases/tag/v0.2.0-data-20261105). All eight snapshots have byte sizes and SHA256 checksums in [the manifest](../docs/ARTIFACTS.json). The current platform data are directly available in [market.json](../platform/public/data/market.json).

These are retained research snapshots. Extracting them does not fetch new market data or regenerate new forecasts automatically. Original data formats, field names and source-language notes are preserved.
